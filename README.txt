Angel Cinematic Birthday Website

How to use:
1. Open index.html in your browser.
2. Replace music/song.mp3 with your legally downloaded MP3 file.
3. The website already uses the 5 real photos you uploaded.
4. To host it, upload this whole folder to Netlify or GitHub Pages.

Important:
- The YouTube link cannot be used directly as background music. Put an MP3 file named song.mp3 inside the music folder.
